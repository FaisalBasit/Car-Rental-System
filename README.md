# Car Rental System

A Computer Organization and Assembly Language project that simulates a menu-driven car rental system.

## Features

- Rent cars by vehicle type and duration
- View rental records
- Delete rental records
- Track total vehicles rented
- Track rentals by Ferrari, BMW, and Mercedes
- Calculate rental earnings
- Enforce rental limits

## Concepts

- Assembly language programming
- Menu-driven application design
- Conditional statements
- Loops
- Record management

## Purpose

The project demonstrates how fundamental programming and record-management concepts can be implemented in an assembly-language car rental simulation.
